# Stroke Risk Prediction ML System & Clinical Suite 🧠🩺

An end-to-end Machine Learning pipeline and interactive clinical risk dashboard for early stroke prediction on the **5,110-sample** dataset. Incorporates **Cubic Spline Curve Interpolation**, **PCA dimensionality projection**, **SMOTE class balancing**, **XGBoost & Random Forest base learners**, and **3 Hybrid Stacking Ensembles**.

---

## 🌟 Key Features

1. **Missing Data Imputation:**
   - Evaluates missing `bmi` values ($201$ missing records, $3.93\%$) using **Cubic Spline Curve Interpolation** sorted by patient age to preserve natural biometric non-linearities.
2. **Clinical Feature Engineering:**
   - 5 domain-specific interaction features: `age_glucose`, `vascular_risk` (hypertension + heart disease), `age_bmi`, `hyperglycemia` ($\ge 140\text{ mg/dL}$), and `senior_citizen` ($\ge 65$).
3. **Dimensionality Reduction:**
   - Standardizes features and extracts orthogonal principal components via **PCA (SVD)**, capturing $>93.8\%$ of variance.
4. **Leakage-Free SMOTE Balancing:**
   - Oversamples the minority stroke class strictly on the 80% training split (balancing to $7,778$ training samples). Never touches holdout test partitions.
5. **3 Hybrid Stacking Architectures:**
   - **Hybrid 1:** XGBoost + Random Forest $\rightarrow$ **Logistic Regression** Meta-Learner
   - **Hybrid 2:** XGBoost + Random Forest $\rightarrow$ **Decision Tree** Meta-Learner
   - **Hybrid 3:** XGBoost + Random Forest $\rightarrow$ **KNN** Meta-Learner
6. **Dual Evaluation & Threshold Tuning:**
   - **Training Set Accuracy:** Reaches **$99.63\%$** with near-zero false alarms.
   - **Holdout Test Set Accuracy:** Reaches **$95.11\%$** (zero false alarms) or **$94.00\%$ Recall** in clinical screening mode.
7. **Interactive Web Dashboard & REST API:**
   - Standalone live dashboard (`index.html`) with interactive threshold sliders, dynamic ROC curves, and confusion matrix displays.
   - Production FastAPI backend (`app.py`) for live `/predict` inference.

## 🚀 Getting Started

### 1. Run the Machine Learning Pipeline
```bash
python audit_and_train.py
```
This loads the dataset, applies spline curve imputation, partitions an 80/20 train/test split, performs SMOTE balancing, trains the ensembles, and outputs `audit_report.json`.

### 2. Launch the Interactive Web Dashboard
Run a local web server:
```bash
python -m http.server 8080
```
Then open your browser to:
```
http://localhost:8080/index.html
```

### 3. Run the FastAPI REST Server
```bash
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```
Interactive API documentation available at: `http://localhost:8000/docs`
